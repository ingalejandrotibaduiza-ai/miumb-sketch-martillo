# Martillo

ERP especializado para gestionar el ciclo administrativo de casas de subastas pequeñas y medianas.

## Alcance

Catálogo, consignación, subastas y lotes, comisiones, liquidaciones y reportes. No incluye puja en tiempo real, pasarela de pagos ni aplicación móvil nativa.

## Tecnologías

- Java + Spring Boot
- PostgreSQL
- React
- JWT
