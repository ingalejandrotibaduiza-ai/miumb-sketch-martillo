# Terraform - Sprint 2

Esta carpeta contiene una implementación académica de Infraestructura como Código para el ERP Joyería Martillo Dorado.

## Importante
No se crean recursos reales en AWS, Azure o GCP para evitar costos. El objetivo es demostrar estructura, versionamiento y validación de Terraform.

## Comandos
```bash
cd infra/terraform
terraform fmt -check
terraform init
terraform validate
terraform plan
```
