# Documentación ERP Joyería Martillo Dorado

## Descripción

Documentación inicial del proyecto académico de Ingeniería Web I para construir un ERP web de joyería.

## Secciones

- Sprint 1: `docs/sprint-1.md`
- Backlog tipo Jira: `docs/jira_backlog_sprint1.csv`
- Trazabilidad: `docs/trazabilidad.md`
- Código principal: `index.html`, `styles/styles.css`, `script.js`

## Módulos del ERP

1. Inventario de joyas.
2. Ventas.
3. Clientes.
4. Proveedores.
5. Reportes.

## Arquitectura objetivo

Frontend con HTML, CSS y JavaScript. Backend futuro con Node.js y Express. Base de datos futura con MongoDB.
