# ERP Martillo

Sistema para la gestión administrativa de casas de subastas pequeñas y medianas. Proyecto de la asignatura de Ingeniería de Software, Universidad Manuela Beltrán, 2026.

## Alcance

Catálogo, consignación, subastas y lotes, comisiones, liquidaciones y reportes. No incluye puja en tiempo real, pasarela de pagos ni aplicación móvil nativa.

Tecnologías: Spring Boot, PostgreSQL, React y JWT.
