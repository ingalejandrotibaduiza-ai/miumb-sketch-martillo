# 11. Riesgos y deuda técnica

## Riesgos
- Que el prototipo se quede solo en localStorage y no evolucione a backend real.
- Que no se definan referencias únicas para cada joya.
- Que el equipo no mantenga trazabilidad entre Jira, commits y documentación.
- Que el diseño no se pruebe en dispositivos móviles.

## Deuda técnica actual
- Falta conexión real con base de datos.
- Falta autenticación y roles.
- Falta módulo de ventas completo.
- Falta validación del lado servidor.

## Mitigación
- Planear Sprint 2 con Node.js, Express y MongoDB.
- Mantener Jira actualizado.
- Usar Pull Requests para integrar cambios.
- Documentar cada decisión importante.
