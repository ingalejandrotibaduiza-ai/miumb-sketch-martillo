# 9. Decisiones de arquitectura

## ADR-001: Iniciar con front-end funcional
Se decide construir primero un prototipo front-end para validar la experiencia del usuario y demostrar los temas del curso.

## ADR-002: Usar localStorage en Sprint 1
Se usa localStorage para simular persistencia sin necesidad de backend durante el primer avance.

## ADR-003: Preparar API REST
Se documentan contratos GET, POST, PUT y DELETE para facilitar el paso a Node.js + Express.

## ADR-004: Organizar trabajo con Jira y GitHub
Se usa Jira para backlog y GitHub para control de versiones, ramas, pull requests y evidencias.
