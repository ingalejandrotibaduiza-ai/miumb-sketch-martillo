# 3. Contexto y alcance

## Contexto de negocio
Joyería Martillo Dorado S.A.S. necesita controlar piezas de alto valor comercial. El registro manual genera riesgo de pérdida de información, errores de stock y dificultad para consultar piezas por referencia.

## Usuarios principales
- Administrador de inventario.
- Vendedor de mostrador.
- Encargado de proveedores.
- Gerencia de la joyería.

## Sistemas externos futuros
- Pasarela de pago.
- Servicio de facturación.
- Base de datos MongoDB.
- API REST para consultar y actualizar joyas.

## Alcance del avance
El avance incluye landing profesional, formulario, dashboard, consulta, canvas, contenido editable y persistencia local. No incluye autenticación real ni base de datos externa todavía.
