# 4. Estrategia de solución

La solución se plantea como una plataforma web incremental.

## Sprint 1
- Front-end funcional en HTML, CSS y JavaScript.
- Simulación de datos con localStorage.
- Registro y consulta de joyas.
- Dashboard básico del inventario.

## Sprint 2
- Construcción de backend con Node.js y Express.
- API REST para joyas, clientes, ventas y proveedores.
- Conexión a MongoDB.

## Sprint 3
- Autenticación de usuarios.
- Roles administrativos.
- Reportes avanzados.

## Decisión principal
Se inicia con prototipo funcional para validar la experiencia antes de construir el backend completo.
