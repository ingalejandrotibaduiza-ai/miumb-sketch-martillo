# 2. Restricciones

## Restricciones académicas
- El avance debe demostrar los temas de HTML/CSS/JavaScript trabajados en clase.
- El Sprint 1 debe evidenciar Scrum, backlog, Definition of Done y avance funcional.
- El sistema debe estar versionado en GitHub.
- El tablero debe estar representado en Jira.

## Restricciones técnicas
- En el Sprint 1 se usa front-end estático con HTML, CSS y JavaScript.
- La persistencia es simulada usando localStorage.
- El backend real con Node.js, Express y MongoDB queda planeado para siguientes sprints.

## Restricciones de negocio
- Cada joya debe tener referencia única.
- El inventario debe permitir trazabilidad básica por proveedor y certificado.
- El dashboard debe mostrar información clara para administración.
