# 1. Introducción y objetivos

## Sistema
ERP Joyería Martillo Dorado S.A.S.

## Objetivo general
Diseñar una plataforma web tipo ERP para centralizar la administración de inventario, ventas, clientes, proveedores y reportes de una joyería ficticia.

## Objetivos específicos
- Registrar joyas con referencia, categoría, material, precio, stock, proveedor y certificado.
- Consultar joyas por referencia para apoyar la venta y trazabilidad.
- Visualizar indicadores básicos del inventario.
- Preparar la arquitectura futura con Frontend, API REST y MongoDB.

## Alcance Sprint 1
El Sprint 1 se concentra en el módulo de inventario y en un prototipo front-end funcional con persistencia simulada usando localStorage.
