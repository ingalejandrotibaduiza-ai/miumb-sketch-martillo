# 8. Conceptos transversales

## Usabilidad
La interfaz debe ser clara para usuarios administrativos sin conocimiento técnico.

## Trazabilidad
Cada joya se identifica mediante una referencia única y puede relacionarse con proveedor y certificado.

## Calidad visual
El diseño utiliza colores oscuros, dorados y tarjetas limpias para representar una joyería premium.

## Persistencia
En Sprint 1 se usa localStorage. En siguientes sprints se reemplazará por MongoDB.

## Seguridad futura
Se recomienda implementar login, roles, validación del lado servidor y protección de endpoints.

## Mantenibilidad
El código está dividido en HTML, CSS, JavaScript y documentación en carpeta docs.
