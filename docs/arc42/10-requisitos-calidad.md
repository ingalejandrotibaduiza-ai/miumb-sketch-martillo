# 10. Requisitos de calidad

## Usabilidad
La página debe permitir registrar una joya sin instrucciones complejas.

## Rendimiento
El prototipo debe cargar rápido porque usa archivos estáticos.

## Mantenibilidad
Los archivos deben estar organizados por responsabilidades: HTML, CSS, JavaScript y documentación.

## Escalabilidad
La arquitectura futura permitirá agregar módulos de ventas, clientes, proveedores y reportes.

## Seguridad futura
El backend deberá validar datos y proteger operaciones administrativas mediante autenticación.

## Criterio de aceptación global
El avance debe poder demostrarse en navegador y estar respaldado por GitHub, Jira y documentación.
