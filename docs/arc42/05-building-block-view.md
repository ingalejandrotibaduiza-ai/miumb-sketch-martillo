# 5. Vista de bloques de construcción

## Bloques principales

### Interfaz web
Contiene la página principal, formulario de registro, dashboard, consulta por referencia y secciones informativas.

### Módulo de inventario
Administra el arreglo de joyas, validaciones y actualización de indicadores.

### Módulo de consulta
Permite buscar una joya por referencia y mostrar su información principal.

### Módulo de almacenamiento local
Guarda joyas y notas editables usando localStorage.

### Backend futuro
API REST construida con Node.js y Express.

### Base de datos futura
MongoDB para persistencia real de joyas, clientes, ventas y proveedores.
