# 12. Glosario

| Término | Definición |
|---|---|
| ERP | Sistema de planificación de recursos empresariales. |
| Joya | Producto comercial de la joyería, como anillo, cadena, reloj, pulsera o aretes. |
| Referencia | Código único usado para identificar una joya. |
| Stock | Cantidad disponible de una pieza. |
| Proveedor | Empresa o persona que suministra joyas, materiales o accesorios. |
| Certificado | Documento que respalda autenticidad o características de una joya. |
| API REST | Interfaz para comunicar frontend y backend mediante rutas HTTP. |
| LocalStorage | Almacenamiento local del navegador usado para simular persistencia. |
| Sprint | Iteración de trabajo dentro del marco Scrum. |
| Definition of Done | Criterios que debe cumplir una tarea para considerarse terminada. |
