# Documentación de Arquitectura ERP (arc42)

Este directorio contiene la documentación inicial del ERP Joyería Martillo Dorado S.A.S. organizada con la estructura arc42.

## Secciones
1. Introducción y objetivos.
2. Restricciones.
3. Contexto y alcance.
4. Estrategia de solución.
5. Vista de bloques de construcción.
6. Vista en tiempo de ejecución.
7. Vista de despliegue.
8. Conceptos transversales.
9. Decisiones de arquitectura.
10. Requisitos de calidad.
11. Riesgos y deuda técnica.
12. Glosario.

## Uso académico
La documentación respalda el Sprint 1 y sirve como base para evolucionar el proyecto hacia Node.js, Express y MongoDB.
