# Sprint Review y Retrospectiva

## Sprint Review

### Sprint Goal
Entregar un prototipo funcional del ERP para Joyería Martillo Dorado S.A.S. que permita registrar joyas, consultar referencias, visualizar indicadores y documentar la arquitectura inicial.

### Incremento presentado
- Página web profesional del ERP de joyería.
- Dashboard con total de joyas, valor de inventario y stock.
- Formulario funcional para registrar joyas.
- Consulta de joyas por referencia.
- Persistencia simulada usando localStorage.
- Documentación arc42 inicial.
- Backlog creado en Jira.
- Repositorio GitHub actualizado.

### Resultado frente al Sprint Goal
El Sprint Goal se considera cumplido para el alcance académico del Sprint 1. El prototipo demuestra la solución visual y funcional inicial, aunque el backend real queda planeado para Sprint 2.

## Retrospectiva

### Qué salió bien
- Se logró una interfaz visual atractiva y coherente con una joyería premium.
- Se conectó Jira y se crearon épicas, historias y tareas.
- Se actualizó el repositorio de GitHub.
- Se organizó documentación de arquitectura.

### Qué se puede mejorar
- Evitar trabajar directamente sobre main.
- Crear Pull Requests desde el inicio del desarrollo.
- Separar mejor el front-end del futuro backend.
- Automatizar pruebas en el siguiente sprint.

### Acciones para Sprint 2
- Implementar Node.js + Express.
- Crear API REST de joyas.
- Conectar MongoDB.
- Agregar autenticación de administrador.
- Implementar pruebas automatizadas básicas.
