# English Video Script - Minimum 2 Minutes

Hello, my name is Alejandro Tibaduiza Morales. In this video I will present a short summary about the implementation of the Scrum framework in a modern software development project, applied to our ERP system for Joyería Martillo Dorado.

Scrum is an agile framework that helps teams organize work in short cycles called sprints. In our project, Sprint 2 focuses on advanced features and software architecture. The main goal of the sprint is to implement stock critical alerts, a simulated payroll and commission engine, role-based access control, and Infrastructure as Code using Terraform.

Before starting the sprint, the Product Backlog must be refined. The most important Product Backlog Items must be clear, understandable and prioritized. The Product Owner defines business value, while the development team selects the work that can realistically be completed during the sprint.

The Sprint Backlog includes technical tasks that explain how the work will be done. For example, the stock critical alert requires defining a minimum stock value, creating a validation function, showing the alert in the dashboard, and documenting the decision in arc42. The Terraform story requires infrastructure files, variables, outputs, and a GitHub Actions workflow to run terraform plan in pull requests.

During the sprint, the team uses branches and pull requests. The feature branch is created from develop, then the code is reviewed before merging. This supports quality, collaboration and traceability. Even though this is an academic project with only one member, the workflow simulates a professional development process.

The Definition of Done is also important. For this sprint, the code must be versioned in GitHub, reviewed through a pull request, documented in arc42, and supported by evidence in the laboratory report. Infrastructure as Code must be reviewed and versioned, but it will not be applied to a real cloud account to avoid costs.

In conclusion, Scrum helps us transform a complex project into manageable work. It improves planning, communication, documentation, and continuous improvement. For Joyería Martillo Dorado, Sprint 2 represents a stronger step toward a real ERP architecture. Thank you.
