# arc42 Sprint 2 - Sección 5: Building Block View

## Bloques principales
- Frontend web.
- Módulo de inventario.
- Módulo de ventas y facturación.
- Módulo de clientes CRM.
- Módulo de proveedores y compras.
- Módulo de comisiones/nómina.
- Módulo de seguridad RBAC.
- Módulo de reportes.
- Infraestructura como Código.

## Inventario
Registra joyas, materiales, referencias, stock mínimo y estado comercial.

## Stock crítico
Evalúa si un producto tiene existencias menores al umbral definido. Si ocurre, genera alerta y puede disparar una futura orden de compra.

## Comisiones
Calcula pago simulado de un vendedor usando salario base, ventas del periodo, porcentaje de comisión y deducciones simuladas.

## Seguridad RBAC
Controla qué acciones puede realizar cada rol dentro del ERP.
